This project is built as a proof of concept to demonstrate real-time syncing of Meta Lead Ads data to a React Native mobile application. It is assumed that the Meta Lead Ads webhook setup is correctly configured and accessible via a public URL (e.g., using ngrok), and that webhook verification (GET) and lead event reception (POST) are functioning as expected. For simplicity and due to limited access to production credentials, it is assumed that either a valid Meta Page access token is available to fetch complete lead details using the Graph API, or mocked lead data is used when such access is not available. The backend server, built with Node.js and Express, is assumed to remain continuously running to listen for incoming webhook events and broadcast updates via Socket.IO. The React Native app (built using Expo) is assumed to be active and connected to the backend through a stable network connection to receive real-time updates. It is also assumed that only basic lead fields (such as name, email, and phone number) are required for display, and no complex validation, authentication, or database persistence is implemented in this PoC. Error handling is kept minimal and focused on logging for debugging purposes. The system is designed for demonstration and testing scenarios, not for production-scale deployment, and therefore does not include advanced security measures, scalability optimizations, or retry mechanisms for failed webhook deliveries.
